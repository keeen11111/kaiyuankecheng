版本化，不覆盖

每次调薪生成一个不可变版本，保存变更前后快照与差异；原薪酬记录在双人复核通过并由管理员生效前绝不改动。

双人且不同人

经办人不得自复核，两名复核人不得为同一人，一人只能签一次；四道防线从路由层一直卡到数据库触发器。

人在回路

harness 产出的模型结论只能是建议，状态固定 WAIT_CONFIRM，必须具名人员显式确认后才能进入复核。

数据不出内网

模型端点强制本机／私网白名单，外发上下文只含脱敏字段，薪酬恒为 ****；审计只写摘要哈希不写明文金额。
